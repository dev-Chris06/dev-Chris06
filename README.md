# Christopher AHO GLELE

Développeur full stack, avec un parcours en réseaux informatiques et en génie
logiciel. Je conçois des sites et des applications web pour les entreprises, en
veillant à la sécurité de ce que je construis.

## Projets

**[Gestionnaire de mots de passe](https://github.com/dev-Chris06/password-manager)**
Refonte en cours vers une architecture zero-knowledge : le chiffrement se fait
dans le navigateur, le serveur ne voit jamais les secrets.
Symfony 7.4, TypeScript, WebCrypto.

**[Gestion de clinique](https://github.com/dev-Chris06/Systeme_de_Gestion_de_Clinique)**
Application de gestion de clinique : dossiers patients, consultations,
prescriptions, rendez-vous et historique médical. Accès par rôle
(administrateur, médecin, secrétaire), authentification JWT, stockage de
documents et export PDF.
React, Tailwind CSS, Node.js, Express, SQLite.

**[DIGITECH](https://github.com/dev-Chris06/digitech-site)**
Site d'une agence fictive, réalisé seul lors d'un projet tutoré où j'étais
responsable technique. Bilingue français et anglais.
HTML, CSS, JavaScript.

**[Bénin Tech Labs](https://github.com/dev-Chris06/site-entreprise)**
Site vitrine de sept pages pour une entreprise fictive.
HTML, CSS, JavaScript.
